
## Jobs
`GET /api/jobs` return []Job        Récupère un tableau de jobs
`GET /api/jobs/{id}` return Job     Récupère un job existant
`POST /api/jobs` return Job         Créer un nouveau job (le serveur gère l'id)
`PATCH /api/jobs/{id}` return Job   Modifie un job


# Public
`POST /login`                       Permet de se connecter
`POST /register`                    Permet de créer un compte
`GET /login`                        Frontend login
`GET /register`                     Frontend Register
